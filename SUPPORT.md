# Support

## Community support

Community support is best-effort and free:

- use GitHub Issues for reproducible defects and narrowly scoped feature
  requests;
- use GitHub Discussions for deployment questions, design proposals, and
  general help;
- never post API keys, AWS account identifiers, raw messages, recipient
  addresses, or other sensitive data.

There is no response-time commitment for community support.

## Commercial support

Haya, Inc. keeps the open-source product fully usable without a paid plan.
Organizations may separately purchase services when they need accountable
delivery:

- fixed-scope architecture, deployment, and migration engagements;
- Resend or legacy SES forwarder migration;
- DNS, SPF, DKIM, DMARC, bounce, and complaint readiness reviews;
- security hardening and AWS or Cloudflare account reviews;
- upgrades, monitoring, incident response, and response-time commitments;
- provider migration, conformance review, and failure drills;
- multi-account, regulated-environment, and private-roadmap work.

Commercial terms cover services and warranties, not access to the
Apache-2.0 source code. A public commercial contact and service levels will
be published before the first supported production release. Until then,
start a GitHub Discussion without confidential information.

## Support boundary

Amazon SES deliverability, sending quotas, account suspension, recipient
mailbox behavior, and AWS service availability remain outside HayaSend's
direct control. Paid support can help diagnose and manage these concerns but
cannot guarantee inbox placement.
